# Términos de uso y privacidad de Patitas

## Alcance de la demo

Patitas es un proyecto de portfolio para ejecutar en local. Las fichas de mascotas son ficticias y el formulario sirve para probar el flujo de adopción. Enviar una solicitud registra una prueba en el equipo donde corre el servidor. El formulario no envía correos ni gestiona adopciones reales.

Usá nombres y correos ficticios, por ejemplo `Persona de prueba` y `prueba@example.test`. No ingreses datos de terceros ni publiques el archivo de solicitudes.

## Datos y almacenamiento

El servidor registra el nombre y el correo ingresados, el identificador de la mascota, un identificador de solicitud y la fecha y hora. Usa estos datos para probar la validación y el guardado local. Los registros se agregan a `solicitudes.jsonl` y se conservan hasta que quien opera la instancia los elimine manualmente.

El navegador solicita imágenes a Unsplash y tipografías a Google Fonts. Esas conexiones están sujetas a las políticas de cada proveedor. El formulario envía sus datos al servidor de Patitas.

Si ingresaste datos reales por error, contactá a quien ejecuta esa instancia para pedir acceso, rectificación o supresión. Para información sobre los derechos de protección de datos en Argentina, consultá la [guía de la AAIP](https://www.argentina.gob.ar/aaip/datospersonales/derechos).

## Código y recursos de terceros

El repositorio permite consultar el código de la demo. Cualquier reutilización del código queda sujeta a los permisos que otorgue quien tenga los derechos. Las imágenes y las tipografías se rigen por sus propias licencias. [Licencia de Unsplash](https://unsplash.com/license) · [Preguntas frecuentes de Google Fonts](https://developers.google.com/fonts/faq).

## Antes de habilitar solicitudes reales

Identificá al responsable del tratamiento y publicá su canal de contacto. Definí la finalidad, el plazo de conservación y el procedimiento para ejercer derechos. Revisá los requisitos aplicables a la operación y actualizá este documento para reflejarla. [Ley 25.326, texto actualizado](https://www.argentina.gob.ar/normativa/nacional/ley-25326-64790/actualizacion).
