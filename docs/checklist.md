# Checklist de mejoras

Para marcar una mejora en GitHub, editá este archivo con el ícono del lápiz, cambiá `- [ ]` por `- [x]` y guardá el cambio con un commit. Las casillas completadas se muestran con un tick.

## Fase 1 · Demo local

- [x] Catálogo con filtros por especie.
- [x] Formulario de solicitud por mascota con validación del servidor.
- [x] Guardado local de solicitudes de prueba.

## Fase 2 · Experiencia y pruebas

- [ ] Revisar contraste, foco y navegación por teclado en el catálogo y el formulario.
- [ ] Agregar mensajes de error junto al campo correspondiente y mantener los datos si falla el envío.
- [ ] Optimizar las imágenes y prever una alternativa si una foto externa deja de cargar.
- [ ] Agregar pruebas automatizadas para los filtros y los casos válidos e inválidos de la API.

## Fase 3 · Demo pública para el portfolio

- [ ] Agregar enlaces a los términos de uso y privacidad desde el formulario y el pie de página.
- [ ] En la demo pública, identificar las fichas como ejemplos y evitar la recepción de datos reales.
- [ ] Publicar una demo para el portfolio y enlazarla desde el README.

## Fase 4 · Preparación para solicitudes reales

- [ ] Definir quién administra los datos, por cuánto tiempo se guardan y cómo se eliminan.
- [ ] Migrar el almacenamiento a una base de datos con acceso restringido y copias de seguridad.
- [ ] Incorporar controles contra envíos repetidos y automatizados.
